## 本次最初要求

- **复制后升级：已实现。** 原项目源码不改；完整工作成果位于当前交付副本。
- **现有 SSH 服务作为工作目录：代码与回归已实现。** SSH 档案/主机指纹从原配置复制；新实例无法继承旧进程中的临时密码，真实远端端到端仍受凭据限制。
- **UI 全面优化：已交付可运行界面。** 基础设计变量、多级设置与能力页面均已改造，旧数据/接口保持兼容。
- **Biomni 关键思路与证据模块：已交付轻量可执行子集。** 明确区分独立实现、已查询的公开来源和未安装的上游环境。

不要把此清单中的“部分实现”改成“全部完成”，除非相应子项有实际代码与验收证据。
