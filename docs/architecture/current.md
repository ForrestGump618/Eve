## Nonblocking context integration
Added `desktop/src/context-async.ts`, `desktop/src/context-worker.ts`, and `desktop/test/context-async.test.ts` only. `prepareContextAsync(options, input, signal?)` creates an isolated worker for each request and serializes writers by canonical directory in the daemon process. Queued aborts do not start a worker or write a raw record; running aborts terminate their worker, and the directory queue remains occupied until its exit. Already committed source logs remain preserved. Errors only expose fixed safe codes/messages. Custom CompactionService object injection is intentionally unsupported across the worker boundary. The queue is process-local, so only one daemon may own a context directory.

Validation: strict tsc passed; four async tests passed in 2.05 seconds. Tests verify daemon timer responsiveness during tokenization, same-directory sequential summary versions, queued no-write cancellation, genuinely running cancellation after raw append followed by a second writer, pre-aborted no-directory creation, and redacted worker error messages. Captured options/input prevent caller mutation while queued. The 25-second long-history suite was not rerun for this wrapper-only change. No daemon files modified and no commit made by this agent.
