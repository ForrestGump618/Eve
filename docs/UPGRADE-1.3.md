# OmicsLab 1.3 工作区与界面升级

本版本在复制目录中修改，原项目源码和原运行实例不受影响。

## SSH 作为工作目录

1. 运行根目录的 `启动工作台.ps1`。默认地址 `http://127.0.0.1:8766`。
2. 打开 **SSH** 页，选择已有连接，点击 **测试连接**。密码只在原进程内存中的连接，需要在新实例重新输入一次。
3. 点击 **作为工作区打开**，填写远程工作目录，点击 **验证并打开**。
4. 也可以从工作台 **新建工作区 → SSH 远程工作区** 选择已有连接。
5. 文件、变量、Python 控制台、智能体标准工具、结果面板、后台任务及日志均按当前工作区路由。切换工作区会重置文件浏览位置和控制台显示。

创建前验证远端目录存在且为目录；连接失败明确返回错误。远端路径采用 POSIX 规则，支持 `~` 与 `~/project`。SSH 连接档案和主机指纹已从原项目复制，注册表仅存档案引用，不存密码。系统凭据库不可用时，请重新输入临时密码。

复制过来的模型设置目前是 `mock / mock-model`，可用于界面和执行链路验收；实际智能分析请先在“设置”中配置模型和 API Key。

## 智能体运行链路

- 标准 Python、Shell、读写文件、目录浏览、环境检查、后台进程和 notebook 工具接入 SSH 后端，复用既有连接服务和审批机制。
- 控制台与智能体共享同一个工作区远程 worker，跨轮保留变量，不再误用主内核。
- 系统提示使用实际工作目录，明确远程环境与服务端环境的区别。
- 未知工作区标识报错；不自动退回默认目录。
- 远端 Python 图表写入远端 `figures/`，通过工作区文件接口预览；notebook 导出包含该 worker 的代码历史。
- 远端 worker 随服务关闭或工作区内核停止释放；工作区文件操作结束后释放临时后端。

## 界面

统一为低饱和石墨色 / 浅色主题、青绿色操作强调色。统一按钮、选择框、输入框、焦点状态、留白、圆角、面板层级；尊重减少动画设置。工作台成为默认入口，连接状态区分“待检测 / 可访问 / 不可访问”。审批入口移入导航栏，避免遮挡控制台运行按钮。

## 开源参考

只借鉴交互与设计原则，没有直接移植第三方源码或加入大型前端框架。

| 来源 | 采用的原则 | 本项目实现 |
|---|---|---|
| [VS Code Remote SSH](https://code.visualstudio.com/docs/remote/ssh) | 主机与远程目录组成工作区，执行留在远端 | profile + root + 作用域内核 |
| [OpenChamber](https://github.com/openchamber/openchamber) | 会话、计算与结果放在同一工作界面 | 默认工作台、SSH 页直达工作区 |
| [shadcn/ui](https://github.com/shadcn-ui/ui) | 统一设计变量、清晰控件层级与可见焦点 | 原生 CSS Studio 主题，无 React 迁移 |

## 验证范围与限制

回归测试覆盖原有功能与新增远程路由、断连、工具执行位置、目录验证、下载格式和内核复用。前端完成 Node 语法检查、浏览器中明暗主题与工作区向导检查。

现有 SSH 档案使用密码认证；密码留在原进程内存，新进程未取得密码，因此真实远端端到端尚未验证。测试中的远端连接使用替身；不能据此声称已在你的服务器完成分析。

独立旧版文件、图库、变量页以及 Discovery 项目页仍保留原有作用域；远程工作请使用工作台及 SSH 页。本次没有升级模型本身，也没有重写所有专业分析流程。
