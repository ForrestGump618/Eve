# 路线图（ROADMAP）

本页把 [V2 实现与缺口清单](SUWEN-V2-CHECKLIST.md) 的逐项状态整理成一张可读的路线图，并说明哪些缺口适合外部参与。它只做归纳，不新增承诺；状态定义与判定标准以清单原文为准。

- **已实现**：有实际后端和可用操作，能完成对应任务。
- **部分实现**：已有可用子集，但清单列出的子项尚未完成。
- **待实现**：本包未提供相应能力。
- **外部依赖限制**：需要用户环境、凭据或上游服务，代码本身无法独立补齐。

## 4. 外部依赖限制

以下能力需要用户环境或上游服务，不能用本仓库代码独立完成验收：

| 需求 | 依赖 | 说明 |
|---|---|---|
| 主动视觉与修正 | 真实视觉模型凭据 | 已实现独立视觉连接与图表后复核循环；真实视觉模型未验收，PPT 需先导出图片。 |
| 兼容消息渠道 | Telegram 账户、第三方平台 | WebChat/Telegram 适配层可用；微信/企业微信/飞书/QQ 等原生插件未提供，Telegram 未用真实账户验收。 |
| 科研 Skills | 上游环境与 API | 预装的是自编方法技能；完整 Robin 环境、FutureHouse API、ERA 程序搜索器需要上游提供。 |
| 权限与沙箱 | Docker 主机 | 断网 Docker Python 工具需本机 Docker；未安装时不会回退到主机执行，Docker 实机未验收。 |

另有验证环境限制：macOS / Linux 的 bash 安装与发布脚本已提供，但当前维护环境没有对应主机，尚未实测（见 [INSTALL](INSTALL.md) 与 [VALIDATION-V2](VALIDATION-V2.md)）。

## 5. 明确未提供的能力

清单中“待实现”的子项按领域归并如下，便于判断工作方向：

- **模型与记忆**：主动能力探测、标准 tokenizer、语义摘要压缩、质量学习路由；本地神经嵌入、学习型重排序、自动语义合并。
- **集成与协议**：微信/企业微信/飞书/QQ 原生适配、扫码登录、群聊与附件、断线重连；MCP OAuth 刷新与 sampling/elicitation。
- **任务与工作流**：外部操作的检查后恢复、分布式 worker、父子任务 UI；通用循环节点、模板导入导出、LLM 生成工作流。
- **科研与证据**：论文自动转 MCP 工程、完整 Robin/ERA 上游、独立共识解析器、完整依赖锁与数据版本图、临床级脱敏。
- **平台与治理**：多用户与角色权限、多租户强隔离、插件兼容迁移矩阵、一键灾备恢复、包市场与签名信任链、跨账户凭据迁移。
- **评测与体验**：科研 benchmark、跨模型质量与 Prompt A/B 对比、可访问性审计、情景模板库。

## 6. 怎样参与

- **补真实环境验证**：如果你有 macOS / Linux 主机、真实模型 Key、Telegram 账户或 Docker 环境，按 [VALIDATION-V2.md](VALIDATION-V2.md) 的方式记录命令、版本与结果，提交验证报告比只报告“能用”更有价值。
- **挑一个待实现子项**：优先选择清单里验收条件明确、不会牵连多个子系统的条目；在 Issue 中先说明范围与验收方式。
- **修文档**：发现文档与代码不一致时，附上 `GET /api/health`、`GET /api/runtime/diagnostics` 的输出和对应文件位置；修改实现状态时必须同步 [SUWEN-V2-CHECKLIST.md](SUWEN-V2-CHECKLIST.md)。
- **加测试**：优先补可复现的单元/集成测试，不把模型意见当作通过依据；新增能力需要同时更新清单与验证记录。
- **不要夸大结论**：部分实现不写成全部完成，未验证的真实环境不写成已验证，参考项目按其自身许可证使用，不因参考而成为本包依赖。
