## 使用说明

- 归档文档中的链接已按当前位置修正，指向 `docs/` 下的同名文件；被引用的文件后来移动或改名时，以当前 [`docs/README.md`](../README.md) 为准。
- 归档文件中的本机绝对路径（如 `C:\projects\suwen`）、旧端口与旧版本号保持原样，仅用于说明当时的工作环境。
- 归档文档不接受功能更新，也不作为“已实现”的证据。当前实现状态见 [`SUWEN-V2-CHECKLIST.md`](../SUWEN-V2-CHECKLIST.md)，验证记录见 [`VALIDATION-V2.md`](../VALIDATION-V2.md)。
- 如需引用其中的契约内容，请注明“历史文档，1.2.0 时期”，并优先核对当前代码与 [`API.md`](../API.md)。
