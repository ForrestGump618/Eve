在独立测试 home、显式 mock 模型下，通过 HTTP 创建持久科研任务，允许测试范围内 Python 工具：

- 任务确实调用并成功执行 Python。
- 上下文保留工具结果，避免模型重复执行已完成代码。
- 无可追溯生物学证据时，最终状态为 `needs_review`，没有变成科研验证成功。
- 检查 provenance 中的实际工具执行记录与 evidence_gate。

该链路测试报告见 `validation-v2-live.json`。它验证平台的执行与门控，不验证真实 LLM 的规划、分析或科学发现质量。
