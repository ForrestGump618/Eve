# Eve 1.3.0

## 研究总览

- 默认首页新增“研究总览”，集中显示课题进度、运行质量、Token、请求数、
  耗时、成本、最近会话、最近运行、后续计划和待确认经验建议。
- 趋势图支持 7/30 天范围与四种指标切换，提供鼠标提示、键盘导航和响应式布局。
- 所有 Dashboard 入口复用现有科研愿望、会话、运行和设置流程，不增加独立后台任务。

## 科研与记忆

- 新增用户主动开启的“做梦与经验整理”。只读取当前工作区脱敏材料，候选必须
  通过 Sage 证据门禁并由用户逐条确认。
- 记忆与修正进入可检索知识库；技能草稿保持停用，后续课题保持未启动。
- 新增公共生物医学数据采集技能，以 Collector → Evaluator → Curator 流程记录
  检索、质量评分、字段规约和标准化步骤。

## 界面与配置

- 开局弹窗收敛为标题、目的说明和单一主操作，并支持“下次不再提示”。
- 设置页支持模型温度、上下文窗口、最大输出、Token 参数和输入模态配置；
  权限默认开放且可逐项覆盖。
- 减少聊天、工作台、图表与技能页面中的原始 JSON、代码过程和说明性套话。
- 统一设计令牌、按钮层级、间距、状态反馈与移动端内部滚动。

## 修复与验证

- 修复旧资源查询参数导致的重复 ESM 模块实例。
- 修复科研愿望失败节点重试竞态；提交失败时清理孤立会话。
- 加入有界 Electron smoke 清理，避免 Playwright 在应用退出后无限等待。
- Python：857 passed, 1 skipped；桌面：310 passed, 1 skipped；Dashboard 与
  Onboarding、Wishes、Settings、Artifacts、Teams 真实 Edge 检查通过。
