# 交互图解接入验收

日期：2026-10-28。产品版本：Eve 1.0.0。

## 交付行为

- 技能页可搜索和使用图解技能；支持架构、流程、时序、数据流、生命周期、ER 图、类图、树、时间线、瀑布图和单页说明。
- 聊天回复显示页面卡片，点击预览；文件树可再次打开，预览支持查看源码和下载 HTML。
- 预览初始主题跟随应用。页面脚本在无同源权限的 iframe 中运行，禁止联网、表单提交和导航到应用 API；冻结的内嵌图仍可打开。
- 复用现有技能注册、任务权限、工作区执行接口和 Trace，不增加第二套 Agent Loop。本地和 SSH 使用绑定工作区，连接失败不切换到本地。
- 按需读取参考资源；压缩执行包在注册器内复用。共享库增加 1,308,193 字节，启动不解压整个包。
- 科研绘图保留原来的数据分析、数值和统计方法；图解用于解释结构、流程和结论。

## 问题与修复

| 实际发现 | 原因 | 修复位置 |
| --- | --- | --- |
| 命令行检查通过，应用内提示找不到浏览器 | 桌面 Python 启动的环境白名单缺少 Windows 浏览器安装目录 | `desktop/src/legacy-worker.ts`、`desktop/src/workbench.ts` |
| 工具失败只显示 `[object Object]` | 执行适配器将嵌套错误对象直接转字符串 | `desktop/src/execution-environment.ts`、`desktop/src/daemon.ts` |
| 单页说明的规范文档与原稿绑定不一致 | 原稿 `meta.output` 包含目录，与原生解析器的文件名规范不一致 | `omicslab/execution/archify.py` 提前检查并解释；加载技能时给出参数说明 |
| 纯文本说明页默认不运行浏览器门禁 | 原生默认行为区别于图表 | Eve 的 `finalize` 显式要求浏览器检查；四个门禁全部通过且实际文件存在才返回产物卡片链接 |
| HTML 直接在应用域执行可能接触主窗口与认证接口 | 产物和应用共享来源会扩大权限 | `routes_workspaces.py` 返回惰性 JSON，`artifact-viewer.js` 注入 CSP 与不透明来源沙箱，Electron 拦截子框架导航 |

## 边界

- 远程路由、断连不回退和远程 HTML 读取有测试覆盖；尚未在用户真实 SSH 主机上运行 Node/浏览器生成，不计作远程实测通过。
- 执行主机必须有 Node.js 18+ 和受支持的浏览器；依赖不足会明确失败。资源准备不等于任务完成。
- 隔离预览支持自包含页面，外部脚本、字体、网络访问和打开外部站点受到限制。未承诺所有原生导出格式可在隔离预览中使用；HTML 下载可独立查看。
- 产物上限 2 MB，单次执行最多 120 秒；超过预算不会返回成功产物。
