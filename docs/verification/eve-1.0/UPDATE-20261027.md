# Eve 1.0.0：旧界面与升级启动修复

本记录针对 2026-10-27 晚间构建，承接同目录首次发布报告。原始 `eve-v1.0.0-final`、`eve-v1.0.0` 和 `v1.0.0` 标签不移动。不能因为版本号仍为 1.0.0 就把旧安装包算作本轮修复后的包。

## 根因与修改

| 实际问题 | 根因 | 修改位置与行为 |
| --- | --- | --- |
| 使用期间弹出另一套旧界面 | UI 测试配置模型或测流时显示 `--native` 诊断窗口 | `desktop/src/runtime-identity.ts`、`main.ts`：正常配置只打开正式工作台，诊断入口限显式隔离测试；测试 bootstrap 增加 `--background`，隐藏时继续传递测试流事件 |
| 源码已更新，页面仍由旧后台提供 | daemon 复用只比较 1.0.0 版本号，忽略真实代码目录和资源变化 | `scripts/copy-assets.mjs` 为 TS、UI、Python、worker 和技能资源生成 SHA-256 构建指纹；`main.ts` 与 `daemon.ts` 同时检查指纹和代码路径。无活动任务时安全更换后台，暂停/审批记录保留 |
| 真实历史配置无法进入工作台，空配置测试却通过 | Workbench 已拒绝旧 Python 依赖，main 仍按历史 marker 给 daemon 传入该目录 | `main.ts` 删除未经检查的 `--legacy-deps` 注入；`workbench.ts` 完整检查系统依赖。真实用户配置中的旧 Python 3.11 环境升级为匹配解释器的独立环境后成功启动，历史会话不删除 |
| 接近关闭窗口时主进程异常 | 原生回调或异步启动继续访问已销毁的 BrowserWindow | `main.ts`、`window-lifecycle.ts` 检查窗口与 webContents 生命周期，防止关闭后继续显示/发事件 |
| 选择器样式和层次不一致 | 提供商、模型、角色和权限混用原生 select 与独立弹层 | `omicslab/web/js/eve-select.js`、`views/chat.js`、`views/platform.js`、`platform.css` 统一扁平选择器、供应商→模型二级菜单和编辑表单 |
| 大技能库重复访问 SQLite 与遍历词项 | 安装技能和启用状态每次重读；前缀搜索扫描所有词 | `domain/tools.ts` 缓存元数据与状态并在修改时失效；`skill-library.ts` 使用排序词项和按需正文/资源读取 |
| 用户点名文档解析能力时发现不准确 | 无 MinerU 条目，通用描述压过精确名称 | 固定官方 MinerU commit 导入参考技能，完善 PDF/OCR 检索。共 279 个方法技能和 8 个基础技能；方法文本可用不代表 MinerU 服务、模型或依赖已验收 |
| 仍有隐藏回合次数限制 | TS/Python 回合与 UI 创建任务残留 maxTurns/maxTools/maxCalls 等默认值 | 删除统一回合中的固定迭代、重复、无进展次数规则；保留取消、墙钟、Token、超时与检查点。显式研究 DAG 和 MCP 资源限制含义单独记录 |

外部项目 的静态证据、目标功能清单与未知项见 `../clawsgo-1.1.3-rea.md`。未取得其服务端实现，不把未知行为说成源码已确认。

固定任务的最新 P50=9480ms，P95=13225ms，Token=270483；基线分别为 7649ms、21697ms、283308。中位延迟增加，尾延迟和 Token 减少，不能据一次测量声称整体性能提高。工具失败共 3 次，集中在 1 个任务，因此按任务计的恢复率为 1/1。

诊断流测试覆盖 100/1000/10000 个 delta、输入草稿、并发、历史分页和六种尺寸/语言，输入框漂移为 0px。滚动测试原先在内容未溢出时把 `scrollTop=0` 当成用户上滚，导致错误的强制滚动发现；现先确认页面可滚动，再上滚，独立复测漂移 0px。daemon SIGKILL 的独立复测 761ms 自动恢复，未知外部操作仍等待人工核对后才重试，数据库和 DOM 中各一份最终结果。原有失败报告保留，没有删改为通过。诊断 UI 的受控流测试不能替代真实模型或正式工作台验收。

## 复现

```powershell
npm --prefix desktop run typecheck
npm --prefix desktop test
python -m pytest -q
cd desktop
node scripts/startup-build-e2e.mjs --previous=<之前构建的绝对路径/Eve.exe>
$env:SUWEN_WORKBENCH_DEPS=<本机已验证的独立Python依赖目录>
node scripts/formal-ui-e2e.mjs --packaged --credentials=<本地模型凭据> --output-dir=../docs/verification/eve-1.0/formal-current-packaged
node scripts/streaming-ui-e2e.mjs --mode=final --only=kill --runs=1
node scripts/streaming-ui-e2e.mjs --mode=final --only=scroll --runs=1
node scripts/installed-ui-e2e.mjs --endpoint=http://127.0.0.1:<显式启用的本机调试端口>
npm run dist:win
node scripts/verify-doc-hashes.mjs
```

正式用户界面已安装于 `%LOCALAPPDATA%\Programs\Eve`，桌面 Eve 快捷方式指向此目录，参数为空。调试端口仅为本次本机界面核对临时启用，普通快捷方式不携带该参数。
