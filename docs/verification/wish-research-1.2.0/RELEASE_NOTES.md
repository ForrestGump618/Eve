# Eve 1.2.0 - 许愿式科研

Eve 1.2.0 将一句话愿望接入现有持久运行架构：先建立研究章程，再按依赖推进资源侦察、证据矩阵、可证伪假设、预注册、分析、实验设计、图表和人工复核。

## 亮点

- 从聊天或「科研与证据 -> 许愿式科研」建立持久项目。
- 真实文件、阶段目录和 SHA-256 证据门禁；模型不能代替用户结题。
- 同一 durable run 内连续推进，失败可恢复，运行中防重复，阻塞可解释。
- 分析和实验设计在预注册后可并行，由现有持久子智能体按依赖协作。
- 主视图不暴露原始 JSON，只展示阶段、证据、阻塞和工作区入口。
- 1.2.0 安装包保持约 144.3 MB；父版本至当前 Web 源资源增加 38,079 B。
