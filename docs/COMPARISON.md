# 与商业方案的功能对照（COMPARISON）

本文把 OmicsLab 与商业组学分析工作台（以 **OmicOS** 为代表）做功能层面的对照，帮助你在选型时看清差异。

> ## 重要声明
>
> 1. **独立实现**：OmicsLab 是独立开发的开源项目。功能范围参考了同类商业产品**公开文档中描述的能力面**，用于确定产品需求；**不包含、不复制、不提取、不反编译**任何第三方产品的代码、prompt、技能文本、图标或其他资源。
> 2. **无授权绕过**：OmicsLab 不包含、不实现、也不鼓励任何订阅或授权校验的绕过手段。本项目与 OmicOS 及其他商业产品**没有任何隶属、合作或背书关系**。
> 3. **信息来源**：下表中商业产品一侧的信息来自其**公开发布的资料**（官网、公开文档、公开演示）。商业产品迭代很快，具体功能与价格**请以其官方渠道为准**；本文不保证穷尽或永久准确。
> 4. **商标**：OmicOS 等名称与商标归各自所有者所有，本文仅为描述性提及。

## 1. 一句话对比

| | OmicOS（商业） | OmicsLab（开源） |
|---|---|---|
| 定位 | 面向企业/团队的商业组学 AI 工作台 | 本地优先、个人与小团队可自由使用的开源工作台 |
| 授权 | 商业订阅，按档位开放功能与额度 | Apache-2.0，**全部功能免费**，无功能锁 |
| 部署 | 厂商托管 / 企业部署 | 完全本地，`pip install` 即用 |
| 数据 | 依厂商方案，可能涉及云端 | 默认不出本机（只与你配置的 LLM 服务商通信） |
| 扩展 | 走厂商的扩展机制与审批 | Markdown 技能 / Agent + Python 工具，随手改 |

## 2. 功能对照表

图例：✅ 具备 ｜ 🟡 部分具备 / 需自行搭建 ｜ ❌ 不提供 ｜ ❓ 公开资料未明确

| 能力 | OmicOS（商业产品） | OmicsLab（本项目） | 说明 |
|---|:---:|:---:|---|
| **本地 Jupyter Notebook** | ✅ | ✅ | 两者都提供可交互的 notebook 式执行环境。OmicsLab 是**共享常驻内核**：对话、变量面板、后台任务共用同一命名空间；1.2.0 起按工作区/子任务分作用域隔离内核。 |
| **对话式 Agent** | ✅ | ✅ | 自然语言驱动分析、流式输出、工具调用。OmicsLab 支持思维链展示、工具卡片、停止/重发。 |
| **持久运行与恢复** | ✅ | ✅ | 每个回合是有 `run_id` 的持久运行：事件先写 SQLite 再广播，断线按 `after_seq` 续传，进程崩溃后未完成运行对账为 `interrupted`；同一会话并发提交返回 409。 |
| **多工作区隔离** | ✅ | ✅ | OmicsLab 支持注册多个本地/SSH 工作区（默认 `ws_main`），会话绑定工作区，各工作区内核作用域独立，避免变量互相污染。 |
| **统一执行后端** | ✅ | ✅ | 文件、Shell、内核执行都经 `ExecutionBackend`：同一套工具可在本机或远端 SSH 工作区执行，结果标注 `execution_target`；远端不可用时不静默回退本地。 |
| **Agent 可配置** | ✅ | ✅ | OmicsLab 用 Markdown frontmatter 定义 Agent（`omicslab/agents/*.md` 或工作区 `agents/`），无需改代码。 |
| **技能库（Skills）** | ✅ | ✅ | OmicsLab 内置 18 个组学/科研技能包，按需加载 `SKILL.md`；支持环境变量目录覆盖与新增。 |
| **多智能体协作** | ✅ | ✅ | OmicsLab 内置 `lead` + 12 个专职 Agent（含 6 个科研发现/远程计算专职 Agent），Agent 之间可 `delegate_agent` 分派**子运行 + 子任务**；子任务有独立 trace、预算与结果树，父运行取消可级联。 |
| **RSI 科研发现闭环** | ✅（据公开资料有科研 Agent 能力） | ✅ | OmicsLab 内置 7 步闭环（观察→假设→预注册→执行→证据→反思→策略），账本落盘可审查。 |
| **函数注册表（Function Registry）** | ❓ | ✅ | 索引已安装包的函数签名/摘要，Agent 用 `registry_lookup` 查真实 API 后再写代码。 |
| **视觉模型读图** | ✅（据公开资料支持图像） | ✅ | `analyze_image` 接 OpenAI/Anthropic 兼容视觉端点，可解读图表、显微图、门控图。 |
| **SSH 远程算力** | ✅（据公开资料面向大规模分析） | ✅ | 内置 SSH 档案、共享连接与 `ssh_*` 工具（exec/upload/download/info），命令与上传需审批；支持远端真 PTY 终端；不提供集群调度。 |
| **A2A（Agent-to-Agent）协议** | ❓（据公开资料涉及多智能体互操作） | 🟡 | OmicsLab 目前是**进程内**多智能体调度，尚未实现跨进程/跨网络的 A2A 协议；有需要可通过工具自行桥接。 |
| **HPC / 集群调度** | ✅（据公开资料面向大规模分析） | 🟡 | OmicsLab 无内置调度器；可通过 `run_shell` 调用 `ssh` / `sbatch` / `qsub` 接入自有集群，或用后台任务在本地跑。 |
| **云同步 / 团队协作** | ✅（商业云能力） | ❌ | OmicsLab **不做云同步**，数据留在本机；可用 git / rsync / 网盘自行同步 `~/.omicslab` 与工作区。 |
| **轨迹记录（Trajectory）** | ✅ | ✅ | 运行与事件写入 `~/.omicslab/runtime/events.db`（SQLite，可回放）；1.1 的 JSONL 轨迹文件保留只读兼容。 |
| **图表画廊** | ✅ | ✅ | 内核生成的 matplotlib 图自动保存到 `~/.omicslab/figures/`，界面可缩略图浏览、灯箱查看、下载、删除。 |
| **后台长任务** | ✅ | ✅ | OmicsLab 的 `JobManager` 支持 Python / Shell 后台任务、增量日志轮询、取消；不阻塞对话。 |
| **变量浏览器** | ✅ | ✅ | OmicsLab 实时列出内核变量（shape / dtype / head / describe），对 `AnnData` / `DataFrame` 有专门展示。 |
| **文件管理** | ✅ | ✅ | 工作区目录树、上传下载、文本/图片/CSV 预览、新建目录、删除。 |
| **SSE 流式输出** | ✅ | ✅ | 标准 `text/event-stream`；断线按事件 `seq` 续传（`after_seq`），15 秒心跳，事件不乱序不丢失。 |
| **审批 / 权限策略** | ✅ | ✅ | OmicsLab 提供 `auto` / `ask` 两档；`ask` 下 shell、写文件、SSH 执行需逐次确认；审批记录落库、按运行归属，有全局审批中心；可单独关闭 shell / 写文件能力。 |
| **多 LLM Provider** | 🟡（通常以厂商合作模型为主） | ✅ | OmicsLab 预置 14 个 Provider（DeepSeek / 火山方舟 / OpenAI / Anthropic / Qwen / 智谱 / Kimi / Ollama / OpenRouter / 硅基流动 / Gemini / 自定义 OpenAI / 自定义 Anthropic / Mock），可完全离线接 Ollama。 |
| **密钥管理** | ✅ | ✅ | OmicsLab 的 Key 只存本地 `auth.json`，接口永不回传明文；环境变量优先。 |
| **离线可用** | 🟡 | ✅ | SPA 无 CDN、无构建；接 Ollama 后**全链路离线**。 |
| **可自托管 / 可审计** | 🟡（企业版） | ✅ | 纯 Python + 静态前端，代码全开源，可逐行审计。 |
| **中文界面** | ❓ | ✅ | UI 文案与文档以中文为主。 |

> 表中商业产品一侧的 ✅/🟡 表示「据公开资料该能力存在或存在相关方案」，不代表本项目的实现方式与之相同，也不代表其所有档位都包含该能力。

## 3. 免费 / 付费差异

| 维度 | OmicOS（商业） | OmicsLab（开源） |
|---|---|---|
| 收费模式 | 订阅制（档位/席位/额度，以官方定价为准） | 免费，无订阅、无按次计费 |
| 功能限制 | 部分能力按档位开放 | **无功能锁**：代码里有的功能都能用 |
| LLM 成本 | 通常包含在订阅或按额度计费 | 自带 Key，按所用服务商计费；本地 Ollama 零成本 |
| 使用上限 | 依套餐（次数/并发/存储等） | 只受你自己的机器与 LLM 配额限制 |
| 数据位置 | 依厂商部署方案 | 始终在本机 |
| 升级方式 | 跟随厂商发布 | `git pull` + `pip install -e .`，或自行 fork |
| 支持 | 商业支持（依合同） | 社区 Issue / PR；无 SLA |

**结论**：如果你需要**开箱即用的企业级托管、团队协作、商业 SLA**，商业产品是合适选择；如果你需要**数据不出本机、零订阅成本、可改可审计、可离线**，OmicsLab 是同类能力面的开源替代。

## 4. 差异从哪来（方法与边界）

```text
公开资料（官网功能页 / 公开文档 / 公开演示）
        │  只用于确定「需要哪些能力」与「交互形态」
        ▼
OmicsLab 需求清单
        │  从零设计接口、数据结构、prompt、技能文本
        ▼
本项目代码与内容（Apache-2.0）
```

明确**没有**做的事：

- ❌ 没有下载、解包、反编译商业产品的客户端或服务端；
- ❌ 没有读取或复制其 prompt、技能文本、知识库内容；
- ❌ 没有复制其 UI 素材、图标、字体、示例数据；
- ❌ 没有实现、分发或讨论任何授权/订阅校验的绕过方法；
- ❌ 没有冒用其名称、商标或宣称兼容/隶属关系。

如果你认为本项目某处内容与第三方资料过于相似，请提交 Issue，我们会核查并修改或删除。

## 5. 如何自行核实

1. 访问商业产品的**官方渠道**查看其最新功能与定价；
2. 对照本仓库的 [`docs/ARCHITECTURE.md`](ARCHITECTURE.md)、[`docs/API.md`](API.md) 与源码，确认 OmicsLab 的实现方式与来源；
3. 用 `git log` 查看每一行代码的提交记录与作者；
4. 有疑问欢迎开 Issue 讨论。

## 6. 选型建议（务实版）

| 你的情况 | 建议 |
|---|---|
| 数据敏感、不能出内网 | OmicsLab + 本地 Ollama |
| 预算有限的学生 / 个人研究者 | OmicsLab（免费，自带 Key 即可） |
| 需要厂商 SLA、团队账号、云端协作 | 商业产品 |
| 想按自己实验室 SOP 深度定制 | OmicsLab（改 Markdown 技能即可） |
| 需要超大规模 HPC 调度 | 商业方案或自建调度 + OmicsLab 的 shell 工具桥接 |
| 要审计每一步 AI 行为 | OmicsLab（轨迹落盘 + 全开源） |
