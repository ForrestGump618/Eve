# 科学工具使用说明

Eve 预装 40 项科学技能，包含 65 个可执行脚本，以及工作流指引、报告模板和数据库使用说明。技能库按需加载资源，不会在每轮对话中注入全部指引。

## 开始使用

1. 选择本地目录或 SSH 工作区。
2. 打开“能力中心 → Skills”，搜索 `science-` 或数据库名称。
3. 点击“查看与使用”，查看脚本、适用范围和凭据要求。
4. 点击“在对话中使用”，补充问题并发送。该按钮只填写输入框，不会自动发起任务。
5. 在执行轨迹中检查工具返回；需要结果文件时，让 Eve 保存并读取文件核对。

## 可用方向

| 方向 | 示例任务 |
| --- | --- |
| 遗传变异 | 查询 ClinVar 临床记录、gnomAD 人群频率，区分证据与预测 |
| 基因调控 | 分析指定变异的调控影响，结合 GTEx 组织表达和 eQTL |
| 蛋白与结构 | 获取 UniProt 信息、PDB 或 AlphaFold 结构，分析置信度和结构相似性 |
| 药物与靶点 | 查询 PubChem 化合物性质、ChEMBL 活性和 Open Targets 疾病关联 |
| 文献 | 检索 PubMed、Europe PMC、bioRxiv、OpenAlex 和 arXiv，保留原始来源 |
| 功能与通路 | 查询 Reactome、QuickGO、STRING、InterPro 等注释 |

## 依赖与凭据

科学脚本通过 `uv` 运行。当前主机首次缺少运行时时，Eve 会给出安装命令；依赖下载需遵循任务权限。解析后的依赖缓存在执行主机，后续运行可复用。

AlphaGenome 分析需要 `ALPHAGENOME_API_KEY`；部分序列比对服务需要 `USER_EMAIL`。PubMed 的 `NCBI_API_KEY`、OpenAlex 的 `OPENALEX_API_KEY` 和部分其他凭据为可选项；未配置时可先使用对应服务允许的公开查询。

凭据在执行主机的环境变量或 `.env` 文件中配置。不要把密钥粘贴进对话。Eve 的检查结果只返回是否存在，不返回凭据内容。SSH 工作区使用远端的运行环境和凭据；连接失败会返回错误。

结构可视化等能力可能需要额外程序和特定运行环境。选择相关技能后先检查当前主机支持情况。安装了指引不代表这些外部程序已经可用。

## 对话示例

```text
使用 science-literature-search-europepmc 检索 TP53 与肿瘤相关的近期论文，
先返回 5 篇，保留标题、摘要、标识符和来源，再总结共同发现与分歧。
```

```text
使用 science-pubchem-database 查询阿司匹林的分子性质，
将原始结果保存为当前工作区的 pubchem.json，读取文件后给出简短说明。
```

```text
结合 ClinVar、gnomAD 和 GTEx 解释这个变异：
请先核对基因组版本和坐标；分别列出临床记录、人群频率与表达证据。
缺少必要信息时先说明，不把预测当成临床结论。
```

## 执行记录

轨迹保留技能版本、指引哈希、资源摘要、执行工作区、耗时和退出状态。资源被修改、脚本超时、命令失败或输出截断时，运行不会被标记为成功。准备资源和查看命令帮助也不代表完成科研任务。

数据库内容、访问限制和许可各不相同。准备好的技能目录中保留对应条款和原始许可通知；获取论文、结构和数据时仍需遵守其使用条件。
