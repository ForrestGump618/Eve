# Robin 方法技能

来源：https://github.com/Future-House/robin 。版本：public-method-1。此技能为独立操作流程；上游 Robin 组件与 FutureHouse API 没有默认安装或授权。不能声称已运行原始 Robin。

1. 先登记研究目标、已有观测、约束与基线假设。通过 bio_literature_search 查询公开文献元数据，并实际检查其是否支持当前判断。
2. 输出多个竞争解释，为每个解释指定能区分它们的实验或计算结果。记录来源、样本单位、对照、随机化、盲法、指标和停止条件。
3. 获得用户授权后使用当前工作区内核执行分析，保留代码、参数、环境和真实输出。缺少湿实验或外部 API 权限时必须停留在计划阶段，不模拟实验结果。
4. 将结果写到指标 JSON；使用 bio_record_claim 与 bio_verify_claim 检查预先声明的指标。报告负结果与局限，不事后改阈值使检查通过。
5. 依据实际观测修订假设，将旧假设、修改理由和结论版本保留在科研证据中心。关键结论需要独立复核。

示例：分析已有药物筛选数据，找出支持或反驳两个机制假设的观测，再设计能够区分它们的下一轮实验。
