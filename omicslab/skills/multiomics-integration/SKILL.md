# Multi-omics integration

Inventory files, samples, modalities, genome/build, identifiers and covariates before analysis. Run modality-specific QC and record exclusions. Choose integration only after checking batch structure and pairedness. Preserve raw and normalized matrices, parameters, seeds and intermediate artifacts. Validate links with held-out or orthogonal evidence. Produce a compact figure plus an interactive provenance table; conclusions must distinguish association, prediction and causal claims.
