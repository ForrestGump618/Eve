# Paper2Agent 方法工作流

来源：https://github.com/jmiao24/Paper2Agent 。版本：public-method-1。这里是独立实现的操作技能，未安装原项目的多智能体系统。权限：网络检索需确认，文件写入与代码执行遵守工作区权限。

1. 明确论文 DOI / PMID、版本、代码仓库与许可证。使用 bio_literature_search 记录实际来源；不可凭记忆生成不存在的引文。
2. 提取输入数据格式、算法步骤、参数、预处理、随机种子、依赖和原文评估指标。将未公开的信息列为阻碍，不补造。
3. 用 list_files 与 get_system_info 检查当前工作区和运行环境。不得因为主机有 Python 就声称第三方研究依赖已安装。
4. 对公开代码先审查，再由用户批准执行。不得自动运行仓库安装脚本，不加载未知 pickle 文件。
5. 实际运行最小复现，输出原始日志和指标 JSON，并用 bio_record_claim / bio_verify_claim 记录可验证结论。论文指标与本地指标不同必须报告差异，不能将接口能调用当作方法复现成功。
6. 将方法封装成 SKILL.md 或 MCP JSON-RPC 工具草稿，明确输入 Schema、输出、依赖、权限、超时、来源版本与失败条件。未测试的草稿标记为未验证。

示例：读取指定论文及其公开仓库，复现作者的一个公开指标，将方法封装为可测试的 Skill。缺少论文、数据、环境或许可证时先列出缺项。
