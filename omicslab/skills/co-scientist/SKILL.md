# Co-Scientist 方法技能

来源：https://arxiv.org/abs/2502.18864 。版本：public-method-1。基于公开研究方法的独立实现，不冒充 Google 未公开的系统。依赖：已连接的语言模型、可追溯文献与可执行的实验数据。权限：模型调用与工具遵守工作区授权。

先明确研究问题、已知证据、预算、终止条件与可证伪指标。将已知证据、推断、假设分别登记。通过“任务中心 → 多 Agent 讨论”创建有上限的讨论，或使用 delegate_agent 将问题分派给假设、证据、数据和实验设计角色。

每位参与者必须阅读上一轮其他参与者与裁判的意见，提出具体反例和可执行的验证方案。裁判应保留少数意见，并允许下一轮质疑自己。排序依据是证据强度、可证伪性、预期效应、资源与风险，不能把赞同票数当作科学可靠性。

对排名靠前的假设给出可运行的分析或实验设计。执行后将真实指标保存到工作区 JSON，调用 bio_verify_claim 独立检查。最终报告包含结论、反证、未解决问题、关键来源和下一次实验；无法收敛要明确说明原因。

所有科学发现必须通过素问证据门禁。模型共识、文献元数据存在或数值显著性本身都不等于因果结论成立。

示例：比较三种肿瘤免疫调节机制，用两轮交叉批评挑选最值得做的实验，并保留无法排除的替代解释。
