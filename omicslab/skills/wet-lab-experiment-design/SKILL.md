# 湿实验设计

## 先固定统计单位

- **生物学重复**是独立样本、供体、动物、批次或独立培养株。结论的外推和统计自由度按它计算。
- **技术重复**是同一份样本的多次测量，只用于评估移液、上机、成像或读板误差，不能把 `n=3` 个孔说成 `n=3` 个生物学重复。
- 同一供体分到多个处理时属于配对或重复测量，分析必须保留配对/供体结构。
- 一个实验可以有多个技术重复，但主要终点仍要预先指定。

如果只有处理后的汇总值，没有原始读数、样本映射和对照，不进入实验结论阶段。

## 设计卡

执行前写清以下字段：

1. **问题与假设**：一句话说明要检验的因果或机制假设，以及什么结果会否定它。
2. **模型系统**：细胞系/原代细胞/类器官/动物/人源样本，来源、代数、性别、年龄、疾病状态和纳排标准。
3. **独立单位**：供体、动物、独立培养、批次或视野；写明每个处理组的计划 `n`。
4. **主要终点**：唯一、可测量、带单位、时间窗和计算方式。其余终点标为次要或探索性。
5. **对照**：阴性、阳性、载体、未处理、基线、加载量、染色/抗体同型或技术对照，按实验选择。
6. **随机化与区组**：处理和读数顺序如何随机化；批次、板位、笼位、供体或操作者如何形成区组。
7. **盲法**：至少读数和分析阶段对分组编码盲；揭盲时间和条件预先记录。
8. **样本量**：由最小有意义效应（MID）、α、power、预计损耗和多重比较反推；不能先做再补功效。
9. **QC 门槛**：细胞活力、汇合度、支原体、STR、RIN、抗体验证、标准曲线、CV、背景和事件数等，阈值由 SOP 或用户预先给出。
10. **批次与资源**：试剂批号、血清批号、仪器、板号、抗体批号、动物批次、人员、时间和预算。
11. **停止/救援规则**：毒性、污染、QC 失败、无效、样本不足或外部条件缺失时何时停止，不能根据想要的结论继续加样。
12. **数据交付**：原始文件、样本表、单位、板位图、随机化表、处理日志、排除理由、脚本和产物路径。

## 对照选择

| 实验 | 至少考虑 | 目的 |
|---|---|---|
| 细胞处理 | 载体、未处理、阳性对照、空载体/非靶向对照 | 区分溶剂、背景和处理特异性 |
| 细胞活力 | 0 h/接种基线、培养基空白、无细胞空白 | 区分增殖、死亡和读板背景 |
| qPCR | 无模板、无逆转录、参考基因、未处理对照 | 排除污染、gDNA 和归一化漂移 |
| Western blot | 加载量/总蛋白、目标蛋白、阴性/阳性样本、二抗对照 | 区分真实条带和曝光/抗体背景 |
| ELISA | 空白、标准曲线、稀释线性、回收/加标 | 确认标准曲线范围和基质效应 |
| 成像/流式 | 未染色、单染、同型、FMO/生物学阴性 | 设置门控、补偿和阈值 |
| CRISPR/转染 | 非靶向、空载体、未转染、细胞毒性对照 | 区分编辑/递送和选择压力 |

## 样本量与重复的最低写法

- `n` 必须写成“每组多少个独立供体/动物/培养批次”，不能只写孔数。
- 细胞实验至少说明独立培养次数；技术孔数单独列出。
- 小样本探索性实验可以报告效应量和置信区间，但不能把方向性变化包装成确证结论。
- 多重终点要在看到结果前定义比较族和校正方法。
- 预计失败/污染/失访时，计划样本量按 `计划可分析 n ÷ 可分析率` 放大。

## 细胞与分子实验的前置 QC

- 细胞系身份：STR 或供应方证明、代数、污染检查；实验前记录支原体结果。
- 培养基/血清/抗体/试剂：货号、批号、有效期、开封日期；不同批次不能默认等价。
- 原代细胞/类器官：供体伦理、病理状态、培养天数和形态/标志物 QC。
- 人源样本：知情同意、伦理批件、去标识化和最小必要数据；不把受控数据发送到未授权服务。
- 动物：按 ARRIVE 2.0 记录随机化、盲法、样本量、排除、福利和人道终点；方案先获伦理批准。
- 生物安全：确认 BSL 等级、重组 DNA/病毒/CRISPR 递送审批和废弃物流程。

## 标准与追溯

以下公开标准用于设计卡和报告的最低信息自查。标准正文、付费表格和本地法规以官方最新版本及机构 SOP 为准；技能不会替代伦理、生物安全或统计审批。

- 动物研究：ARRIVE 2.0 关键 10 项与完整清单，记录样本量、纳入/排除、随机化、盲法、结果测量、统计、实验动物、实验步骤、福利和解释。https://arriveguidelines.org/arrive-guidelines
- qPCR：MIQE 2.0（Bustin et al., *Clinical Chemistry*, 2025；DOI `10.1093/clinchem/hvaf043`），记录 RNA 质量、逆转录、引物效率、参考基因、技术重复和缺失 Ct 处理。https://doi.org/10.1093/clinchem/hvaf043
- 流式：MIFlowCyt 2.0 最低信息与 ISAC 报告要求，记录样本、panel、仪器设置、补偿、门控、事件数和数据文件。https://isac-net.org/miflowcyt-2/
- 分析性能：涉及仪器/检测方法精密度或线性评价时，参考 CLSI EP05 与 CLSI EP06 的设计思想；它们主要面向临床实验室方法，不能无条件外推到所有研究 assay。https://clsi.org/shop/standards/ep05-plus/ 和 https://clsi.org/shop/standards/ep06/
- 细胞系与试剂身份：细胞系使用 Cellosaurus/RRID，抗体、细胞系和其他关键试剂尽可能记录 RRID、供应商、货号和批号。https://www.cellosaurus.org/faq 和 https://www.rrids.org/rrid-system

交付时必须区分“标准要求”“机构 SOP”“厂家说明”与“本实验自定义阈值”。无法访问标准全文或付费表格时，明确标为待核对，不能凭记忆补造条款。
