Use workspace_info to learn the actual roots. List or search before guessing a filename. Read text using line ranges and nextStartLine; report truncated content honestly. For updates, use write_file with the latest read_file sha256 as expectedSha256. A user supplied absolute file path is readable directly. Do not claim a file was read or written before a successful tool result.
